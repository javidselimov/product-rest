FinCERT maliyyə bazar iştirakçılarına təsir edən kibertəhlükəsizlik insidentləri barədə məlumatların mərkəzləşdirilmiş formada toplanmasını və vaxtında paylaşılmasını təmin edir.

FinCERT bu istiqamətdə:

  • qanunvericilik çərçivəsində CERT-lər ilə sıx kommunikasiya və əməkdaşlıq həyata keçirir;
  • maliyyə bazarlarında kibertəhlükəsizlik səviyyəsinin artırılmasını təmin edən effektiv kommunikasiya mühitini formalaşdırır;
  • beynəlxalq maliyyə CERT-ləri ilə əməkdaşlıq edərək qlobal ən yaxşı təcrübələri tətbiq edir.
