# "Mərkəzi Bankın loqosu" səhifəsinin məzmunu

Admin panel: **Səhifələr → Media → Mərkəzi Bankın Logosu** (test mühitində id `553`, slug `merkezi-bankin-logosu`).

1. AZ dilini açın, redaktorda mənbə rejimini (`</>` düyməsi) yandırın, `az.html`-in hamısını yapışdırın.
2. Başlığı `Mərkəzi Bankın loqosu` edin. Slug-ı dəyişməyin.
3. Cədvəlin hər sətrinin **birinci xanasına** loqo şəklini qoyun (kursoru xanaya qoyub şəkil düyməsi).
4. EN dilini açın, eyni addımları `en.html` ilə edin. Başlıq `Central Bank logo`, slug `central-bank-logo`.
5. Səhifənin **Sənədlər** blokunda «Sənəd əlavə et» ilə hər format üçün bir ZIP arxivi əlavə edin: `cbar-logo-svg.zip`
   (bütün loqoların SVG-ləri), `cbar-logo-png.zip` (bütün loqolar bütün ölçülərdə), `cbar-logo-pdf.zip` (bütün loqoların
   PDF-ləri; EPS də buraya). «Başlıqları redaktə et» ilə adlarını yazın: `SVG`, `PNG`, `PDF` (və ya `PDF / EPS`). Arxivi
   necə yığmaq: `dokumentasiyalar/merkezi-bankin-logosu-guide.md`, «Format arxivləri».
6. Yadda saxlayın.

Şəkillər qoyulana qədər saytda kartlar boş önizləmə qutusu ilə görünür, Hero isə görünmür.

EN mətn Figma-dakı AZ mətnin qaralama tərcüməsidir, dərcdən əvvəl redaksiya yoxlamalıdır.

Cədvəlin qaydası: sütunlar `Şəkil | Ad | İzah | Fon`, fon `açıq` və ya `tünd` (`light` / `dark`).
Ətraflı: `dokumentasiyalar/merkezi-bankin-logosu-guide.md`.
