# "Media sorğuları" səhifəsinin məzmunu

Admin panel: **Səhifələr → Media → Media Sorğuları** (id `519`, slug `media-sorgulari`).

1. AZ dilini açın, redaktorda mənbə rejimini (`</>` düyməsi) yandırın, `az.html`-in hamısını yapışdırın.
2. Başlığı `Media sorğuları` edin. Slug-ı dəyişməyin.
3. EN dilini açın, eyni addımı `en.html` ilə edin, başlıq: `Media inquiries`. Slug-ı dəyişməyin.
4. Yadda saxlayın.

EN mətn Figma-dakı AZ mətnin qaralama tərcüməsidir, dərcdən əvvəl redaksiya yoxlamalıdır.

Sonradan redaktə üçün: cədvəlin hər sətri bir kartdır, sütunlar `Ad | Dəyər | Əlavə mətn`.
